celld on Railway

Your node is connected to object storage and ready to run Cloudflare Workers and Durable Objects. 

# 1. Link to your Railway project
railway link

# 2. Deploy your Worker
railway run --service celld --no-local -- celld deploy .

# 3. Restart the node to load the deployment
railway restart --service celld --yes

This starter is installed only when the fleet bucket is empty. Running celld deploy replaces it.
